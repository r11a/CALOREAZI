# CALOREAZI

CALOREAZI is a private, AI-assisted nutrition experience for Home Assistant.

## Install in Home Assistant

1. Open **Settings → Add-ons → Add-on Store**.
2. Open the repository menu and add `https://github.com/r11a/CALOREAZI`.
3. Install **CALOREAZI**, start it, and open the Web UI or sidebar panel.

Version `0.1.0` is the first installable preview. It includes the responsive Hebrew dashboard, light/dark themes, the approved brand system, health checks, and the initial token-aware AI usage foundation. Camera analysis, authentication, persistence, and live AI provider configuration remain staged work.
