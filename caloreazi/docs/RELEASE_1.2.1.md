# CALOREAZI 1.2.1

## Fixed

- Every built-in fruit and vegetable now maps to its own photographic sprite cell; new foods no longer repeat the apple or tomato image.
- Timeline events now remain horizontal inside one vertical timeline and no longer create unnecessary horizontal scrolling.
- The README, changelog, health endpoint and service-worker cache version are updated again with every release.

## Goal-aware history

- Calories display consumed versus the recommended daily target.
- Protein, carbohydrates and fat display actual versus recommended grams.
- Blue means below target, amber means near target, green means within target range and red means above target.
